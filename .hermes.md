# Musictui2 — Project Context

Cross-platform terminal music player that streams audio files directly from GitHub repositories.

Tech stack: **Rust (2018 edition)** · CLI + TUI architecture · async runtime (tokio)

---

## Architecture Overview

```
src/
├── main.rs          # CLI entry point (clap), dispatches subcommands
├── models.rs        # Core data models: Repository, Track, PlaybackState, AudioMetadata, AppConfig
├── cli/mod.rs       # Cli struct — orchestrates add/list/remove/scan commands
├── tui/mod.rs       # Ratatui-based TUI — 3-tab interface (Repositories / Tracks / Now Playing)
├── github/mod.rs    # GitHub API client — recursive repo scanning, file download
├── database/mod.rs  # SQLite persistence (rusqlite) — repositories + tracks tables
├── cache/mod.rs     # SHA256-keyed file cache with LRU eviction (1GB default cap)
├── audio/mod.rs     # Rodio-based audio player — play/pause/stop/volume
└── events/mod.rs    # EventBus (mpsc channel) — pub/sub for cross-module communication
```

## Implemented Features

### CLI Commands
- **add** `<repo>` — Add a GitHub repository by URL or owner/repo format; auto-triggers scan
- **list** — List all added repositories from SQLite
- **remove** `<repo>` — Remove repository by ID or owner/repo (cascading delete of tracks)
- **scan** `<repo>` — Scan a repository recursively for audio files and report results
- **tui** — Launch the terminal UI

### GitHub Integration
- Recursive directory traversal via GitHub Contents API
- Audio format filter: mp3, flac, wav, ogg, m4a, aac, wma
- Anonymous API access with rate-limit tracking (5000 req/h)
- File download with caching

### Database Layer (SQLite)
- `repositories` table: id, owner, name, url, added_at, last_scanned
- `tracks` table: id, repository_id, path, name, format, size, duration, url, local_path, downloaded
- CRUD operations: save, get, delete (by id or by name), update_last_scanned

### File Cache
- SHA256 hash-based filename deduplication
- Configurable max size (default 1GB)
- LRU eviction on cleanup
- Cache info query (total size, file count)

### Audio Playback
- Cross-platform output via rodio (Core Audio / WASAPI / ALSA)
- Play, pause, stop controls
- Volume adjustment (0.0–1.0, clamped)
- Playback progress query (get_pos)
- Track duration display

### TUI (ratatui + crossterm)
- 3-tab layout: Repositories / Tracks / Now Playing
- Header with repo/track counts
- Footer with keyboard shortcut hints
- Keyboard: Tab/Shift+Tab switch tabs, Enter play, Space play/pause, +/- volume, q quit

### Event System
- EventBus with mpsc channels (subscribe/publish)
- Events: RepositoryAdded, RepositoryRemoved, TrackDiscovered, TrackDownloaded, PlaybackStarted/Paused/Stopped, VolumeChanged, Error

## Conventions

- All modules use `mod.rs` layout under `src/`
- Error handling via `Box<dyn std::error::Error>` (no custom error types yet)
- Database path: `~/.config/musictui2/music.db`
- Cache directory: `~/.config/musictui2/cache/`
- Supported audio extensions: mp3, flac, wav, ogg, m4a, aac, wma
